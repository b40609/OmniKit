# OmniKit 規則：安全底線

規則版本：2026-11-14-1

所有人都套用這一份。個人規則（`data/profiles/<名稱>/AGENTS.md`）可以更嚴，不能放寬這裡的任何一條。

## 先確認才做
- 刪除類操作：刪檔、清空目錄、`git reset --hard`、`git push -f`、`git clean -fd`，以及資料庫 DROP、TRUNCATE 或改 schema。
- 對外發送：寄信、發訊息、發文、留言。
- 付款、購買，以及修改系統或安全設定。

## 金鑰與下載
- 不讀取、不印出、不寫死 API key、token、私鑰與密碼；需要時用環境變數參照。
- 不執行來路不明的下載檔。

## 誠實回報
- 沒測過就不能說通過；測試結果要附實際輸出。
- 跳過或做不到的步驟要講明，不要略過不提。
