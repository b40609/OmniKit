# 替你做的決定（v2）

只用 `.agents/skills/taste-skill`，內容只取自 `content/README.md`。

## 方向

1. **風格**
   - 深色的 Apple 產品頁，參照 iPhone Pro 官網：黑底、大字、一屏只講一件事。
   - 品牌色取自 App 本身：底色 #000、字色 #f5f5f7、主色 #007aff（App 的強調藍）、卡片 #161617。
   - 字型用 Geist 配 Noto Sans TC。
2. **主要檢查尺寸**是 1920×1080。各屏都在這個尺寸實際截圖看過，另外也跑了 1440、1024、820、768、390、375、320。
3. **全部用真實畫面**。每一屏的圖都是 OmniKeep 示範版的真實截圖，沒有任何手繪的介面或示意圖。
4. **不用 shader 或 3D 特效。** skill 允許軟體頁加特效，但 Apple 風格靠產品畫面撐場，所以不加。
   - 只用兩個 moment：
     - 「資料在你自己手上。」用 liquid-type。
     - 安裝區的平台名稱用 marquee-row。
   - 系統設定為「減少動態」時，跑馬燈會停成一排靜態文字，這是 kit 的預期行為。

## 內容

5. **頁面順序**：英雄區（一句話說明 + 真實收件匣）→ 3 個步驟 → 摘要與重點分析 → 提問 → 能做的事（兩屏）→ 資料在你手上 → 安裝 → 收尾。
6. **一句話說明**寫成「Telegram 連結收藏，裝在你自己的電腦。」，依據是 README 的定位：自架、Telegram 為主要入口、資料在本機。
7. **README 中刻意沒放的內容**：
   - 常見問題。
   - 疑難排解。
   - 更新步驟。
   - 開發者指令。

   這些放進官網會把一頁拉成文件。頁尾的「更新到新版」「回報問題」連回 GitHub。
8. **實驗功能**（探索、每日回顧、專案監看）只在「能做的事」的標題下用一行交代：預設關閉，要用再到設定開啟。不另外做成賣點。
9. **安裝指令**一字不改照抄 README。
   - Windows 與 macOS／Linux 兩段都有複製按鈕。
   - 「幫我安裝 OmniKeep」那句話放在最前面，因為 README 寫它是最省事的裝法。
10. **沒有任何數字、評價或客戶標誌。** 「3 步」「3 分鐘」都是 README 原有的說法。

## 截圖與示範資料

11. **15 則收藏**照 Ryan 給的順序收進示範版。
    - App 的「子專案展開」自動多收了 11 則被提到的專案，已用 App 的刪除 API 刪掉。
    - 為了讓卡片照順序排，收錄時間改成每則間隔 3 分鐘。
    - 細節寫在 `C:\Users\user\.omnikit-wp1-demo\screens\README.md`。
12. **網頁上的裁切**只做縮放與裁切。手機版另外裁一張直式，因為詳情頁與影片列表若直接縮小，在手機上看不清楚。
