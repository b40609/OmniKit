OmniKeep

收了的連結，
終於找得到。

在 Telegram 把連結丟給自己的機器人，它把網頁、影片、社群貼文讀完寫成摘要，之後用搜尋或提問找回來。資料存在你自己的電腦上。

三個動作。你只做第一個，讀完與整理交給 OmniKeep，要用的時候在同一個搜尋框裡找回來。

OmniKeep

丟連結。在 Telegram 把連結傳給自己的機器人，或在 OmniKeep 按頂部的「新增」貼上。

它能做什麼

丟連結就收錄

主要入口是 Telegram。其他管道也都通。

  • Telegram 機器人
  • LINE 官方帳號
  • 網頁上的「新增」
  • iOS 捷徑
  • PWA
  • MCP
  • REST API
Telegram 機器人
用一次性配對連結綁定你的帳號，收錄後回覆摘要卡。
網頁上的「新增」
貼連結、寫筆記、把書籤檔拖進來都從這裡。
外部 agent（MCP）
同一台電腦用 stdio，別台電腦用 Streamable HTTP；安裝腳本會自動註冊到 Claude Code、Codex、Antigravity。
REST API
附 Swagger 文件，方便腳本與自動化流程串接。

網頁、影片、社群貼文
都讀得懂

YouTube
接上 Google Gemini 時直接解析影片；沒有就讀字幕，沒字幕用本機語音轉錄（中文用台灣華語微調的 Breeze-ASR-25），逐字稿帶 [MM:SS] 時間與章節。
Bilibili 長影片
先用官方 CC／AI 逐字稿，沒有時改抓音訊交給本機 faster-whisper 轉錄（選用安裝）。
Reels、TikTok、Shorts
關鍵幀 OCR 加語音轉錄，兩邊的文字合併後再分析。
長文與永久快照
清掉廣告與雜訊，存一份 HTML 快照；原網頁失效後仍然看得到。

找得到

搜尋、提問、篩選，都在同一個搜尋框。

全文檢索
SQLite FTS5 用 trigram 分詞，中文句子裡的子字串也找得到；不到三個字的詞改用 LIKE 比對。
語意搜尋
向量索引和全文檢索的結果合併，關鍵字對不上時也找得到相關內容。
提問
先檢索相關的收藏，再交給 AI 回答，回答附上引用的來源編號。

先看摘要，
需要再看重點

摘要
卡片上是一個說重點的標題、一兩句白話說明，以及標籤。
重點分析
打開收藏可以看完整的分析，以及 Markdown 原文閱讀模式。

實驗功能

功能在、可以開，但介面與行為還會改。新安裝預設關閉。

探索
定時檢查你加的來源（RSS、YouTube 頻道、GitHub 專案、Google News 關鍵字、網頁變動），挑分數最高的幾篇分析，整理成精選。
逐則篩選
一則一則決定要不要留，喜歡與不喜歡會調整之後的排序。
每日回顧
每天挑幾則未讀和值得重看的舊收藏。
專案監看
掃描你指定的本機資料夾，產生風險與改進的建議。

資料，
留在你的電腦上。

收藏都存在本機的一個 SQLite 資料庫，不放在別人的雲端。服務預設只聽這台電腦，別台裝置連不到。

  • 127.0.0.1

    預設只綁本機位址，別台裝置連不到

  • 每天

    自動備份一次，資料庫與 HTML 快照一起

  • 3 種

    備份去處：本機多份輪替、rclone 雲端同步、私有 Git 儲存庫

  • 末四碼

    你在 App 裡輸入的金鑰加密後才存，之後只顯示末四碼

稍後讀服務

服務可能終止，資料綁在廠商的雲端，而且多半只保存文字。

三分鐘開始用

最省事：對 Claude Code、Codex 或 Antigravity 說一句

幫我安裝 OmniKeep：https://github.com/b40609/OmniKeep

agent 會幫你安裝，再帶你接上 AI、接上 Telegram、丟第一個連結。金鑰與機器人權杖一律在 OmniKeep 的設定頁自己貼，不經過聊天。

也可以自己執行安裝腳本

Windows PowerShell 5.1 或 PowerShell 7

& ([scriptblock]::Create((irm https://raw.githubusercontent.com/b40609/OmniKeep/main/scripts/install.ps1).TrimStart([char]0xFEFF)))

終端機

curl -fsSL https://raw.githubusercontent.com/b40609/OmniKeep/main/scripts/install.sh | bash

需要 git、Python 3.12+、Node.js 20.19+ 或 22.12+。

  1. 打開在這台電腦用瀏覽器打開 http://127.0.0.1:5000，直接進主畫面，不用登入。安裝後會自動接上不用註冊的免費 AI 服務。
  2. 接上 Telegram找 @BotFather 傳 /newbot 建立機器人，把權杖貼到「設定 › 收錄管道 › Telegram」，再用配對連結綁定你的帳號。
  3. 丟第一個連結傳給機器人，處理完它會回一張有摘要的卡片。還沒接上 AI 也能收藏，之後會在背景補分析。
