## 開場
訂單查詢頁（orders/）剛寫好的時候看假資料都很正常，今天接上測試環境才發現，資料還在抓的時候畫面一片空白、查不到東西也沒提示，客戶名稱太長還會把表格撐爆。我要怎麼要求才不會每次都漏掉這些狀況？

## 處境
你是客服組長，這個訂單查詢頁是你們每天查單用的。工程師請 agent 寫的，接上測試環境才發現一堆狀況。你不會寫程式。

## 想要的結果
- 資料在抓的時候要看得出來「正在載入」。
- 查不到訂單時要有提示，例如「查無訂單，請確認訂單編號」。
- 查詢失敗（網路斷掉、伺服器出錯）時要告訴使用者失敗了、可以再試一次，不要一片空白。
- 客戶名稱很長時不能把表格撐爆。
- 原本正常的訂單列表不能壞。

## 細節
- 測試環境的 API 有時候要等 3 秒以上才回來。
- 客戶名稱最長大概 60 個字（公司全名）。
- 偶爾 API 會逾時。
