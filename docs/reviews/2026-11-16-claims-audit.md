## 還沒修的

### A 級

換與換回（上面第 1 項）：
- ADV-07、WK-01：換回時只比對名冊的 `kind`。新工具還沒拿掉、或撞名時，會假報「已經換回」。
- WK-02：`swap start` 當時查不到某一類清單也照記。之後換回永遠卡在 `reverting`，槽位鎖死。
- WK-03：`swap adopt` 把沒寫 `kind` 的舊工具一律當 skill，偵測到同名的 plugin 也說「沒裝」。

安裝與移除（上面第 2 項）：
- INS-1：`agents.json` 記過同名，就認定是 OmniKit 的 skill。使用者自己換上的同名 skill 會被刪掉（`agents.py:219`）。
- INS-2：舊版 skillshare 的設定還在時，使用者自寫的 `~/.codex/AGENTS.md` 會被覆寫，或被移除時刪掉。
- INS-3：舊版帳本沒有雜湊（`e is None`）時，移除不比對內容就刪 MCP（`agents.py:1031`）。
- INS-4：安裝前就有、設定剛好一樣的 MCP，被默默改成 OmniKit 管，移除 OmniKit 時一起刪掉。
- INS-5：`uninstall.ps1 -KeepTools` 不清安裝紀錄。之後正式移除時，會刪掉使用者後來自己加的權限規則。
- INS-6：找不到 uv 時跳過大部分清理，卻刪掉安裝紀錄，還印「已從這台電腦移除」。
- INS-7：Claude MCP 更新是先 remove 再 add。add 失敗時整個 server 就沒了。另外 npm 裝的 `claude.CMD` 會展開 `%APPDATA%`，讓 JSON 解析失敗。
- INS-10：`-Fresh` 在沒裝 Claude Code 的電腦會崩潰；備份檔名對不齊，還原會漏掉後來的備份。
- INS-11：讀設定檔不處理 UTF-8 BOM。移除時只要一個設定檔壞掉，後面的清理全部中止。
- INS-12：安裝寫到一半失敗時沒存 `agents.json`，移除就跳過 skills 與 MCP。
- INS-13：`npm ls` 解析失敗時，會把原本就有的全域套件記成 OmniKit 裝的，移除時一起卸載。

INS-10、13 是審查者讀程式碼推論的，沒有實際重現。其餘都有重現輸出。
