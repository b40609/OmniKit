# 產品簡介附錄：OmniKit v2（同事版）

放產品簡介裝不下、但後續 PRD 與設計會用到的細節。

## A. 現況資料（2026-11-05）

- 名冊：116 張卡片。預設 11 張（7 張是 agent 內建功能 native-*），試用 1 張（chrome-devtools-mcp），待評估 104 張。
- 真正需要安裝的預設工具只有 bmad、frontend-design、rea、skill-creator。
- 15 個槽位中：7 個的預設是內建功能；指令輸出壓縮、工具發現、行為準則包 3 個沒有預設；訪談第 1 題的「資料分析」沒有對應槽位。
- 每週深度評估上限 2 次（`data/omnikit.yaml` 的 `eval.weekly_deep_limit`），104 張全部評完要將近一年。
- 預設工具不會自動安裝：`engine/scripts/install.ps1:408`。

## B. 2026-11-04 Codex 瘦身實測

| 項目 | 停用前 | 停用後 |
|---|---|---|
| 載入的 skill | 112 個 | 32 個 |
| 對話開頭的 skill 清單 | 49,335 字元 | 15,877 字元 |
| 同一個問題的 token | 27,038 | 19,695 |

做法：依 `engine/scripts/usage.py` 的使用紀錄，在 `~/.codex/config.toml` 用 `[plugins."x@y"] enabled = false` 與 `[[skills.config]] name = ...` 停用。跟帳號同步的 plugin（例如 sites、work-pets）只能用後者。
