- 日期：2026-11-05
- 審查對象：`docs/v2/brief/brief.md`、`docs/v2/prd/prd.md`（只審查，沒有改動原文）
- 方法：BMAD v6.12.4 `bmad-review` 的 structure 與 prose 鏡頭（doc_standards：`skill:bmad-review lenses=structure,prose`），每份文件先跑 structure，再跑 prose

- 讀者類型：humans（請求沒有指定，沿用 skill 預設）
- 風格依據：請求中陳述的使用者規範優先（繁體中文台灣用語、不用 LaTeX、精簡高密度、需要讀者決定的事放前面、術語第一次出現要讓不熟的人看得懂、不要中英夾雜到影響閱讀）；其餘以 skill 預設的 Microsoft Writing Style Guide 為基準

- 標籤：MOVE（移動位置）、MERGE（合併）、CONDENSE（精簡）、CUT（刪除）、QUESTION（請作者決定）、PRESERVE（看似可刪，建議保留）

## 最值得先改的 5 項

1. **待決事項集中到文件開頭**：brief 的 6 個 `[ASSUMPTION]` 散在全文；PRD 的待解問題、假設索引與 2 個 `[NOTE FOR PM]` 都在文末或埋在內文。見 B-S1、P-S1、P-S2。
2. **PRD 的 MVP 範圍有缺口**：§6 沒有歸類 FR-27 前半（兩週試用、轉成預設）。見 P-S3。
3. **版本與階段用語不一致**：「v1」「第一版」「第一階段」「v2.1」「MVP」混用；「v1」容易被讀成現有版本，「第一階段」跟 PRD §7 的階段編號衝突。見 B-P2、P-P3。
4. **「通知」與「建議」混用**：PRD 的 SM-2、SM-C2、UJ-2 把 FR-16 的主動通知叫成「建議」，兩套頻率上限掛在兩個很像的詞上。見 P-P2。
5. **術語第一次出現沒有說明**：brief 的名冊、槽位、凍結、RIA；PRD 詞彙表缺凍結、active、品味題、盲選、同步層、工具類型。見 B-P1、P-P5。

另有一處一字修正值得順手改：PRD §1「核心主張是不是幫你裝更多」少了冒號，會被讀成疑問句（P-P1）。
